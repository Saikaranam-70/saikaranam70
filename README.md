# Sai Karanam — Personal Developer Portfolio Website

A stunning, fully responsive, production-ready personal developer portfolio for **Sai Karanam**, Full Stack Developer & Problem Solver. Built with **Next.js (App Router)**, **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## 🚀 Live Demo & Repository
- **GitHub Repository:** [https://github.com/Saikaranam-70/saikaranam70](https://github.com/Saikaranam-70/saikaranam70)
- **Local Dev Server:** `http://localhost:3000`

---

## 🛠️ Technology Stack
- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typography:** Plus Jakarta Sans & Caveat (Google Fonts)

---

## ✨ Features & Architecture
- **Light Theme Only:** Clean, professional developer aesthetic with subtle blue & purple gradient accents.
- **Hero Section:** High-resolution portrait cutout with floating orbital ellipse, decorative doodles (*"Dream Bigger, Build Better"*), and dynamic animated role cycler.
- **Stats Bar:** Glassmorphism card with animated scroll-triggered counters (`5+ Projects`, `1+ Year Experience`, `8.5 CGPA`, `100% Dedication`).
- **About Me:** Developer workspace showcase, academic details, and quick facts panel.
- **Services & Solutions:** 4 interactive cards with mouse-following radial spotlight glow covering Full Stack Web Apps, Backend & Cloud Architecture, Performance & SEO Optimization, and Healthcare Solutions.
- **Technologies I Work With:** 10 official tech cards (Java, Spring Boot, Python, Django, .NET, React, Angular, Node.js, MongoDB, PostgreSQL).
- **Featured Client Projects:** Real-world healthcare platforms built by **Kolors Digital Services**:
  1. **Dr. G. Rakesh Vamsi** — Consultant Urologist & Andrologist (KIMS Hospital, Nellore)
  2. **Dr. B. Sahithi Priya** — Endocrine & Breast Oncology Platform
  3. **Dr. Bammidi Sandeep** — Surgical Oncology Practice Portal
- **Experience & Leadership:** Dual timeline highlighting engineering contributions at *Kolors Digital Services* and *Bhuma Infotech*, paired with the *"Let's Work Together!"* gradient card.
- **Testimonials:** Verified client and collaborator endorsements with 5-star ratings.
- **Education & Credentials:** Aditya University B.Tech CSE (8.5 CGPA) + verified technical certifications.
- **Interactive Cursor & Scroll Progress:** Smooth spring cursor follower on desktop and top gradient scroll progress bar.
- **Interactive Contact Modal:** One-click email copy with instant feedback, direct email trigger, and message form.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
